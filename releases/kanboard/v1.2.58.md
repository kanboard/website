### Security fixes

* Strengthen SSRF protection for webhooks and web link previews:
  * Connect to the IP address that passed validation, so a DNS change between the check and the request (DNS rebinding) can no longer reach a private network.
  * Block more non-public address ranges, such as carrier-grade NAT, benchmarking, and documentation networks.
  * The `WEBHOOK_ALLOW_PRIVATE_NETWORKS` and `EXTERNAL_LINK_ALLOW_PRIVATE_NETWORKS` options still turn off these checks.
* Reject empty LDAP passwords. Active Directory accepts them as unauthenticated binds, which allowed LDAP users without two-factor authentication to be logged in through the API without a password.
* Apply brute-force protection to two-factor authentication codes:
  * Invalid codes count toward account lockout.
  * The failed login counter is reset only after a valid code is entered.
* Invalidate the login CAPTCHA after each attempt so it cannot be reused.
* Enforce comment visibility in notifications and feeds:
  * Users are notified only about comments their role allows them to see.
  * Project notification channels and activity feeds receive only comments visible to standard users.
* Prevent disclosure of data from other projects:
  * Board tooltips and the "close all tasks" dialog now check that the column and swimlane belong to the project.
  * Public task views no longer show links to tasks in other projects.
  * Mention suggestions no longer list members of projects the user cannot access.
* Validate task references and permissions:
  * Check that the column, swimlane, and category belong to the task's project when tasks are created, edited, moved, imported, made recurring, or bulk changed.
  * Allow only users who can be assigned in the project to be set as task assignee, including in CSV imports.
  * Require permission to create tasks in the destination column when copying or moving a task to another project, and list only the destinations that pass.
* Restrict iCal feeds:
  * Remove assignee and creator email addresses.
  * Exclude tasks from projects the user was removed from, and from inactive projects.

### Improvements

* Add an optional iCal feed that also lists open tasks without dates as to-dos (`VTODO`):
  * Use the new "iCal feed with undated tasks" link on the project and user sharing pages, or add `todo=1` to an existing feed URL.

### Bug fixes

* Fix several iCal feed issues:
  * Write dates in UTC and make sure every event ends after it starts, as required by RFC 5545.
  * Detect all-day events using the timezone of the feed owner or the application, instead of the server.
  * Prevent tasks from appearing twice, and stop listing every open task without due date when the creation date is used as the start date.
  * Use globally unique event identifiers and the task modification date as `DTSTAMP`.
  * Fix the empty organizer email, the escaping of URLs, quotes, and parameters, and the missing final line break.
  * Use absolute task URLs, and make links in task descriptions of project feeds work for readers without an account.
* Fix "database is locked" errors with SQLite when several requests update the session at the same time.
* Fix a fatal error when the comment or email forms are opened in a new tab instead of the modal dialog.
* Keep the task time estimate when the "Add a subtask and activate the timer when moving a task to another column" action creates a subtask.
* Show time spent with two decimal places.
* Remove remaining PHP 8.5 deprecation warnings.

### Maintenance

* Pin tool versions and container images in the GitHub Actions workflows.

### Dependencies and build

* Replace third-party libraries with built-in implementations:
  * `eluceo/ical` for iCalendar feeds
  * `phpqrcode` for 2FA QR codes, which are now rendered as SVG
  * `gregwar/captcha` for the login CAPTCHA
  * `christian-riesen/otp` for TOTP codes
* Update Symfony components to 6.4 and `psr/log` to 3.0.
* Remove unused dependencies: `symfony/stopwatch`, `symfony/finder`, `doctrine/instantiator`, and the Symfony polyfills for ctype, mbstring, PHP 7.3, and PHP 8.0.
* Update `docker/login-action`.
